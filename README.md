# The Mane House – Website

Website for The Mane House, a hair salon suite in Greenwood, AR.

- `index.html`: the whole site (one page)
- `assets/`: logo files and favicon

## Making changes
Edit `index.html` directly on GitHub (pencil icon) and commit. GitHub Pages republishes in about a minute.

## Hosting
Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)`.
